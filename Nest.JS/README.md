# Nest.JS Interview Questions and Answers

This section covers interview questions related to Nest.JS.

## Question 1: What is Nest.JS?
**Answer:** Nest is a framework for building efficient, scalable Node.js server-side applications. It uses progressive JavaScript, is built with and fully supports TypeScript, and combines elements of OOP, FP, and FRP.

## Question 2: Explain Providers in NestJS.
**Answer:** Providers are a fundamental concept in Nest. Many of the base Nest classes may be treated as a provider – services, repositories, factories, helpers, and so on. The main idea of a provider is that it can inject dependencies.
