# Angular Interview Questions and Answers

This section covers interview questions related to Angular.

## Question 1: What is Angular?
**Answer:** Angular is a platform and framework for building single-page client applications using HTML and TypeScript. Angular is written in TypeScript.

## Question 2: What is data binding in Angular?
**Answer:** Data binding represents the synchronization of data between the model and view. Angular provides forms of data binding like interpolation, property binding, event binding, and two-way data binding.
