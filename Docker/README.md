# Docker Interview Questions and Answers

This section covers interview questions related to Docker.

## Question 1: What is Docker?
**Answer:** Docker is a set of platform as a service (PaaS) products that use OS-level virtualization to deliver software in packages called containers. Containers are isolated from one another and bundle their own software, libraries and configuration files.

## Question 2: What is a Dockerfile?
**Answer:** A Dockerfile is a text document that contains all the commands a user could call on the command line to assemble an image.
