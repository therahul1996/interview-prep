# NodeJS Interview Questions and Answers

This section covers interview questions related to NodeJS.

## Question 1: What is Node.js?
**Answer:** Node.js is an open-source, cross-platform, back-end JavaScript runtime environment that runs on the V8 engine and executes JavaScript code outside a web browser.

## Question 2: What is the Event Loop in Node.js?
**Answer:** The event loop is what allows Node.js to perform non-blocking I/O operations — despite the fact that JavaScript is single-threaded — by offloading operations to the system kernel whenever possible.
