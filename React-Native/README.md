# React Native Interview Questions and Answers

This section covers interview questions related to React Native.

## Question 1: What is React Native?
**Answer:** React Native is an open-source UI software framework created by Meta Platforms, Inc. It is used to develop applications for Android, Android TV, iOS, macOS, tvOS, Web, Windows and UWP by enabling developers to use the React framework along with native platform capabilities.

## Question 2: How does React Native differ from React?
**Answer:** React is a framework for building web applications using JavaScript, while React Native is used to build mobile applications for iOS and Android using JavaScript and React.
